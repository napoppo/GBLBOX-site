# ランディング用の画面素材

`device-*.png` は、2026年8月26日に接続したiPhoneのGBL Box実機画面から取得した素材です。

現在のランディングでは、画面上部を見せるCSS表示にして、画面下部の広告確認UIを訴求素材として表示しないようにしています。

- `device-detail.png`：個体詳細、リーグ順位、進化後の評価
- `device-tools.png`：ツール一覧
- `device-simulator.png`：技カウント
- `device-gbl.png`：GBL戦績分析

同じ日に取得した候補画像は、掲載画面を選び直すときの材料としてサブディレクトリに残しています。
